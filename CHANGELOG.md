# Changelog

## 0.1.1

First release from GitHub Actions, with npm trusted publishing and provenance. The CLI and the MCP server behave as in 0.1.0.

- The release workflow publishes without a token and pins its actions.

## 0.1.0

First release.

- Commands: `login` (browser sign-in or `--key`), `logout`, `whoami`, `generate`, `designs`, `gallery`, `styles`, `pricing`, `buy`, `open`, and `mcp`.
- MCP server with the tools `generate_tattoo`, `list_styles`, `get_account`, `search_gallery`, `get_pricing`, `create_checkout`, and `login`.
