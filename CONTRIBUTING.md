# Contributing

Bug reports and ideas are welcome in [GitHub issues](https://github.com/ciroartz/inkstudioai-cli/issues).

This repository is a copy of the CLI folder from the private Ink Studio AI repository. Each change there is copied here by an automated commit. A pull request here cannot be merged directly; we apply accepted changes in the main repository, and they come back here with the next copy.

Run the tests with `npm test` (Node.js 18.17 or later, no install step).
